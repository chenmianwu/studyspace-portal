# 学习中心 · 公网版

这是「在家用局域网 / 外出用云端模型」里的**外出入口**，纯静态，不含任何后端和本地数据。

## 它是什么

- 在外面（没有家里电脑时）打开这个页面，可以直接向语文 / 数学 / 英语 / 总助手提问
- 对话走你自己的大模型 API（DeepSeek / Kimi / 通义千问 / 自定义），需要先在页面里填 API Key
- 提问、回复、记的错题都存在**你这台手机的浏览器里**
- 回到家后，把数据导出成文件，再用家里局域网页面导入 → 写进电脑的 `错题总表.xlsx` 和对话账本

## 怎么用

1. 打开页面 → 点顶栏「外出模式」
2. 第 1 块「接大模型」：选服务商 → 填 API Key → 点「测试连接」确认能通
3. 直接去任意学科模块的「在线对话」区提问
4. 想记错题：弹窗第 4 块填表 → 「加入待导入」
5. 回家后：弹窗第 5 块「导出为文件」→ 回家用局域网页面「从文件导入」→ 再点「导入到电脑」

## 注意

- 公网版本**不能**连接家里的服务（跨域 + 家里是内网地址），所以对话用云端模型、错题要手动搬运
- API Key 存在浏览器 localStorage 里，只在自己的常用设备上配置
- 本目录由 `网页/build_release.py` 自动生成，不要直接在这里改代码——改开发目录后重跑脚本
